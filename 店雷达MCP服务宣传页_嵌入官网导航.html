Get Started

三步接入，5 分钟上手

无需写代码，复制密钥与地址，粘贴到你的 AI 客户端即可。

1

注册并获取密钥

访问 店雷达 MCP 页面，登录后一键生成专属密钥（API Key）与服务地址，新用户可领取免费点数。

2

在你的 AI 客户端添加 MCP

选择下方对应的客户端，粘贴服务地址与密钥，启用「店雷达」连接器。详细图文教程见 配置文档。

Coze（扣子）：创建 / 打开 Bot → 插件 → 添加 MCP 服务 → 远程服务 → 填入服务地址与密钥 → 保存后新开对话即可提问。
ChatGPT：设置 → 连接器（Connectors）→ 自定义 MCP → 填入名称、服务地址与密钥 → 启用后开始对话。完整步骤见配置文档「ChatGPT」章节。
WorkBuddy：连接器管理 → 添加 MCP 服务 → 粘贴服务地址与密钥 → 启用「店雷达」连接器 → 新开会话直接提问。
Codex：运行 codex mcp add 店雷达 --url 服务地址，或在配置文件中声明 mcpServers，重启后即可调用。
自定义客户端：任意支持 MCP 协议的客户端（Dify、Cherry Studio、Chatbox 等），在 MCP 配置中声明右侧的 mcpServers 即可。
3

新开对话，开始提问

添加 MCP 后建议新开一个聊天窗口，让 AI 加载工具。然后直接说：
“使用店雷达 MCP，帮我找出近期有增长趋势的跨境新品”

FAQ

常见问题

?MCP 是什么？和浏览器插件有什么区别？+
MCP（Model Context Protocol）是一种让 AI 客户端连接外部数据服务的开放协议，你可以把它理解为「AI 的标准插座」。插件只在一个平台里生效；MCP 是一次接入、多处通用——配置一次，Coze、ChatGPT、WorkBuddy、Codex 等所有支持 MCP 的客户端都能调用店雷达的选品能力。
?接入需要写代码吗？+
不需要。在 MCP 页面 复制密钥与服务地址，在 AI 客户端里粘贴启用即可。详细的客户端图文教程见 配置文档。
?支持哪些 AI 客户端？+
目前提供 Coze（扣子）、ChatGPT、WorkBuddy、Codex 等客户端教程；只要是支持 MCP 协议的客户端（Dify、Cherry Studio、Chatbox 等），都可以通过填写 mcpServers 配置接入。更多客户端指南陆续上线中。
?调用会消耗点数吗？如何计费？+
每次工具调用消耗 1 点，新用户注册可领取免费额度。可在 MCP 页面随时查看剩余点数与到期时间，点数不足时前往 购买页面 充值。
?返回的数据是真实的吗？+
是的。数据直接来自 1688 平台，与店雷达选品中心同源，包含真实销量、销售额、榜单与销售趋势，不经过任何加工编造。
?AI 返回的商品链接能直接打开吗？+
可以。工具返回真实商品链接（goodsUrl），点击即可跳转到 1688 对应商品页查看详情或下单采购。
